Examples of Context-Free Grammars

A CFG that generates a language of strings of 1 or more 'a's.

S → a
S → aS

A CFG that generates a language of strings of 0 or more 'a's.

S → ε
S → aS

A CFG that generates a language over Σ = {0, 1} of strings that end in 1.

S → A1
A → 1A | 0A | ε

A CFG that generates a language over Σ = {0, 1} of strings that start with 0 and end in 1.

S → 0A1
A → 0A | 1A | ε

A CFG that generates the language {aⁿbᵐ | n > 0, m > 0} over Σ = {a, b}.

S → AB
A → a | aA
B → b | bB

A CFG that generates the language {aⁿbᵐ | n ≥ 0, m ≥ 0} over Σ = {a, b}.

S → AB
A → ε | aA
B → ε | bB

A CFG that generates the language {aⁿbᵐaⁿ | n > 0, m > 0} over Σ ={a, b}.

S → aSa
S → aBa
B → bB
B → b

A CFG that generates the language {aⁿbᵐcᵐd²ⁿ | n >= 0, m > 0} over Σ = {a, b, c, d}.

S → aSdd | X
X → bXc | bc

A CFG that generates palindromes over Σ = {0, 1}.

S → 0S0 | 1S1 | ε | 0 | 1

A CFG that generates palindromes over Σ = {0, 1} with odd length and a 1 in the middle.

S → 1 | 1S1 | 0S0

A CFG that generates the language {aⁿbᵐ | 0 ≤ n ≤ m ≤ 2n} over Σ = {a, b}.

S → ε | aSb | aSbb

A CFG that generates the language {aⁿbⁿ | n ≥ 0 } over Σ = {a, b}.

S → ε | aSb

This creates the first irregular language we made some time ago.

A CFG that generates the language of strings of correctly-nested parentheses.

S → ε | (S) | SS

A CFG that generates a language of arithmetic expressions with +, -, *, and parentheses.

Exp → Exp OP Exp
Exp → (Exp)
Exp → <number>
OP → + | - | *

This is a language we'll be trashing and laughing at in the following lectures.
